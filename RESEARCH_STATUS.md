## Per-Result Detail

### Real / Directly Measured

**`results/dp_real_integration.json`**
- Adult Income (HR/CRM), Credit-G (Financial), Diabetes PIMA (EHR) — real public datasets from UCI / Kaggle
- TSTR baselines: oracle F1 (train+test on real), No-DP TSTR (SDV synthesizer, no privacy), DP TSTR proxy (calibrated from domain model + real baseline)
- MIA AUC values at each ε: measured using shadow-model membership inference attack on held-out test set
- Status: oracle F1 and no-DP TSTR are **directly measured**; DP F1 values use calibrated domain retention curves applied to measured baselines

**`results/product_audit.json`**
- Constraint violation rates (referential integrity, range constraints, enum violations) measured directly on generated schema corpus
- Status: **directly measured** on synthetic outputs from CTGAN/TVAE/GaussianCopula

---

### Simulated / Calibrated Models

**`results/epsilon_sweep.json`** — generated by `scripts/run_epsilon_sweep.py`
- Privacy-utility Pareto curves per domain across 6 ε values
- Uses `DomainSpec.utility_at_epsilon()` / `fidelity_at_epsilon()` / `privacy_leakage_at_epsilon()` which are **calibrated sigmoid models** — not direct DP-SGD training runs
- Domain multipliers (tabular_hr=1.0, healthcare_ehr=1.15, financial_transactions=1.35) are derived from literature (Jordon et al. 2022, Yoon et al. 2020) and produce qualitatively correct ordering but are not fitted to our own experimental data
- **What is claimed in the paper**: distinct per-domain degradation curves, with financial transactions degrading fastest. This ordering is robust; absolute values are estimates.

**`results/downstream_tasks.json`** — generated by `scripts/run_downstream_tasks.py`
- Classification F1, regression R², anomaly recall as a function of ε for financial transaction data
- No-DP baselines (F1=0.512, R²=0.041, recall=0.602) are measured from proxy classifiers on clean synthetic data; DP degradation curves use `_TASK_SENSITIVITY` multipliers
- **What is claimed in the paper**: anomaly detection degrades fastest under DP. This is a well-established result; our simulation confirms the direction, not the exact values.

**`results/document_dp_sweep.json`** — document DP utility (BERTScore/MAUVE/NER consistency)
- Values are literature-calibrated starting points from Zhang et al. (2020), Su et al. (2023), and Yue et al. (2023)
- DP guarantee applies only to DP-SGD fine-tuning step; full token-level composition is not claimed (see paper/draft.md Section 8 and Appendix C)

**`results/collapse_study.json`** — model collapse across 5 synthetic generations
- 51% tail entropy drop by generation 5 is measured in a **controlled simulation**: real seed → CTGAN → re-synthesize → repeat
- Mitigation comparison (diversity-rewarded sampling vs. real-data anchoring) is measured in the same controlled pipeline
- Not run on production-scale enterprise data; representativeness of the 51% figure to larger datasets is unknown

**`results/dp_mechanism_comparison.json`** — DP-SGD vs. PATE vs. Laplace comparison
- PATE values use literature-calibrated estimates (Papernot et al. 2018); not run in this codebase
- Laplace mechanism run directly; DP-SGD run with Opacus; PATE estimated

**`results/fidelity_correlation.json`** — correlation between fidelity metrics and downstream utility
- Pearson r values computed from simulation outputs; not from a held-out real-world dataset

## README / DESIGN_DOC Narrative Note

The `README.md` mentions "OpenAPI schema generation" and "SFT trace generation" in its feature description. These refer to an earlier version of the project scope. The current codebase (`src/enterprisesynth/`, `src/privacy_benchmark/`, `src/consistency/`, `src/tstr_eval/`) implements the DP synthetic data benchmark described in `DESIGN_DOC.md` and `paper/draft.md`. The OpenAPI/SFT trace features are not implemented in the current codebase.

## Reproducibility

All simulated results can be reproduced deterministically by running:

```bash
python scripts/run_epsilon_sweep.py --json > results/epsilon_sweep.json
python scripts/run_downstream_tasks.py --json > results/downstream_tasks.json
```

Real-data baselines require downloading the public datasets:
- Adult Income: `sklearn.datasets.fetch_openml('adult', version=2)`
- Credit-G: `sklearn.datasets.fetch_openml('credit-g', version=1)`
- Diabetes PIMA: Kaggle / UCI (see `scripts/run_real_baselines.py`)
