## Section 2: Theoretical Contributions (if any)

**2. If you ran experiments, did you include the experimental setup (e.g., data splits, hyperparameters, whether they were selected with a validation set) in the paper?**

Yes. Appendix A of the paper (`paper/draft.md`) lists:
- All ε values tested: {0.1, 0.5, 1.0, 2.0, 5.0, 10.0}
- Number of seeds: 10 (5 for quick mode)
- Dataset sizes: 1,000 records per schema type
- TSTR split: 70% train / 30% test
- Confidence interval method: bootstrap with 1,000 resamples, 95% CI

**3. Did you report error bars (e.g., with respect to the random seed after running experiments multiple times)?**

Yes. All TSTR and privacy scores report 95% bootstrap confidence intervals.
See `src/privacy_benchmark/evaluator.py` → `evaluate_with_ci()`.

## Section 3: Datasets

**4. Did you include the data you used?**

Yes. `examples/` contains sample files for each domain type.
Full benchmark datasets will be released to HuggingFace Datasets at `anote-ai/enterprisesynth`
(see `paper/dataset_card.md`) upon paper acceptance.

**5. If you collected data, did you include all details of the data collection process?**

All datasets are either:
- Public-domain (UCI, MIMIC-III public demo, CUAD, Kaggle CC0) — sources documented in `paper/dataset_card.md`
- Synthetically generated from public statistics (HR records) — generation code in `src/`

No proprietary enterprise data is included. No personal data from any organization is included.

**6. Does your dataset contain information that might be considered sensitive or private?**

No. The synthetic datasets generated by this benchmark are derived from public-domain data
and evaluated under differential privacy. See `paper/dp_privacy_analysis.md` for the threat model.
